01这次改了什么

整站从「安静的房间」换成了「一间悬在宇宙里的观测站」，配色由暖金转为青蓝。核心变化有八点：

  • 黑洞影像背景：三张 NASA/JPL-Caltech 高清黑洞照片随机轮换，1.6 秒交叉淡入，右下角标注出处。
  • 真实照片墙：光影区换成 12 张来自 Wikimedia Commons 的实景照片，按原始比例瀑布流排布，全部随站点打包。
  • 开屏页：进入站点先看到一张更高分辨率的黑洞影像（缓慢推近、循环播放），正下方是一个透明按钮「- 探寻 -」。
  • 近透明毛玻璃：轮盘与展示框都改成很轻的磨砂玻璃，边框、投影与四角都压到最低，黑洞的光可以透过面板看见。
  • 缩小的双面板：轮盘只留右半圈并缩到 500px 以内，展示框限制在 960px，两者之间空出一片能看见背景的真空区。
  • 天气与 IP 系统已彻底删除：不再嗅探 IP、不再请求天气，相关接口、开关、玻璃天气与配置字段全部移除。
  • 页面本身不滚动：只有展示框内部滚动，内容再长也不会把页面顶开。
  • 内容全部文件化：轮盘读 轮盘/，展示框读 展示框/，改文字、换图片都不用碰代码。
设计约定：除了「左侧轮盘」和「右侧展示框」，页面其他部分都不使用毛玻璃（backdrop-filter）。按钮、阅读层、提示条一律使用实色，以保证层级干净、性能稳定。

02打开与刷新

整个站是纯静态页面，不需要安装、不需要构建、不需要本地服务器：直接双击 index.html 即可，配置通过 <script> 读取，因此在本机文件模式下也能正常运行。

  • 推荐浏览器：Chrome、Edge（Windows / macOS 均可），Safari 16 以上也可以。
  • 修改任何配置文件后，回到浏览器按 Ctrl + F5（macOS：Cmd + Shift + R）强制刷新。
  • 部署到 GitHub Pages、Vercel 或任意静态主机时，把整个文件夹原样上传即可。

开屏页

每次打开站点都会先看到 NASA/JPL-Caltech 的黑洞影像：画面缓慢推近、循环播放，正下方是一个透明按钮「- 探寻 -」。点击按钮、点击画面任意处、按任意键或向下滚动滚轮，都会进入主界面；进入时开屏淡出，露出同一套黑洞背景。

想跳过开屏直接进入，可以在地址后加 ?enter；想直接打开某个分区，再加锚点，例如 index.html?enter#s4 会直接进入「光影」。

静帧模式：在地址后加 ?still（例如 index.html?still）会关闭所有入场动画，方便截图、录屏或排查渲染问题。日常访问不需要加。

03目录结构

所有可编辑的内容集中在两个文件夹里：轮盘决定「有哪些分区」，展示框决定「每个分区里显示什么」。

R/ ├─ index.html 页面骨架（含开屏页） ├─ styles.css 全部样式 ├─ app.js 配置装载、开屏、轮盘与展示框联动 ├─ 使用手册.html 本文件 ├─ assets/ │ ├─ blackholes/ 随机轮换的黑洞背景 │ │ ├─ 01-tidal.jpg NASA PIA20027 │ │ └─ 02-echo.jpg NASA PIA23866 │ ├─ splash-blackhole.jpg 开屏 + 第三张背景（PIA22085） │ └─ photos/ 12 张真实照片（光影瀑布流） │ ├─ hangzhou.jpg kyoto.jpg santorini.jpg │ ├─ tokyo.jpg iceland.jpg paris.jpg │ ├─ newyork.jpg norway.jpg huangshan.jpg │ └─ capetown.jpg sydney.jpg rio.jpg │ ├─ 轮盘/ │ ├─ 索引.js 列出所有轮盘配置，决定顺序 │ ├─ AA-WL-HM-“首页”.js │ ├─ AB-WL-WR-“文章”.js │ ├─ AC-WL-PJ-“项目”.js │ ├─ AD-WL-GL-“光影”.js │ └─ AE-WL-CT-“联系”.js │ └─ 展示框/ ├─ 索引.js 登记每个分区的子文件夹与配置文件 ├─ AA-FR-HM-“首页”/ │ ├─ AA-CF-HM-“首页配置”.js │ └─ AA-CN-HM-“首页内容”.js ├─ AB-FR-WR-“文章”/ │ ├─ AB-CF-WR-“文章配置”.js │ └─ AB-CN-WR-“文章内容”.js ├─ AD-FR-GL-“光影”/ 瀑布流图片墙 │ ├─ AD-CF-GL-“光影配置”.js │ └─ AD-CN-GL-“光影内容”.js └─ …（项目 / 联系 同理）

注意：轮盘/索引.js 与 展示框/索引.js 是两张「目录页」，它们本身不参与编号，但新增分区时必须同步登记，否则页面读不到。

04标记规则

所有分区文件与文件夹统一使用这种格式：

XX-XX-XX-“name”
  • X：必须是两个大写字母（A–Z）。
  • name：给人看的标签，放在中文引号 “ ” 里，机器不读取它的含义。
  • 机器只解析前三段编号；展示框匹配时只看第一段编号。

三段编号的含义

位置含义示例
第 1 段分区编号：AA = 01，AB = 02，AC = 03 … AZ = 26AA → 首页
第 2 段文件域：WL 轮盘 / FR 展示框 / CF 配置 / CN 内容WL、FR
第 3 段家族指纹：同一分区的所有文件保持一致HM 首页、WR 文章、PJ 项目、GL 光影、CT 联系

它们如何对应

轮盘点亮 AA-WL-HM（首页）时，展示框会读取第一段 AA，去 展示框/索引.js 里找以 AA 开头的那一栏，于是打开 展示框/AA-FR-HM-“首页”/，再按其中的配置读取内容文件。

只改标签是安全的：把 AA-FR-HM-“首页” 改名成 AA-FR-HM-“家” 不会影响运行——只要 展示框/索引.js 里的 dir 跟着改。机器比对的是 AA。

05轮盘配置

轮盘决定分区的数量、顺序、名称、图标与强调色。每个分区一个文件，登记在 轮盘/索引.js 里。

轮盘 / 索引.js

window.RAW_WHEEL_INDEX = {
  files: [
    "轮盘/AA-WL-HM-“首页”.js",
    "轮盘/AB-WL-WR-“文章”.js",
    "轮盘/AC-WL-PJ-“项目”.js",
    "轮盘/AD-WL-GL-“光影”.js",
    "轮盘/AE-WL-CT-“联系”.js"
  ]
};

分区配置（例：首页）

RawaeaWheel.add({
  code: "AA-WL-HM",          // 编号，必须与展示框第一段一致
  name: "首页",              // 轮盘上显示的名字
  english: "HOME",           // 展示框右上角的小字
  icon: "home",              // 图标名
  accent: "#9adcff"          // 强调色
});
字段说明
code三段编号，见「标记规则」。决定排序与展示框匹配。
name轮盘、中心圆盘、展示框标题都会用到。
english英文小字，显示在展示框右上角与轮盘旁注。
icon可选：home、writing、projects、gallery、contact、planet、orbit、moon。留空则使用 orbit。
accent该分区的强调色，影响轮盘高亮、标题描点、按钮等。

轮盘的排列顺序由第一段编号决定（AA → AB → AC …），标签在盘面上的位置由数量自动均分，所以增删分区后分布依旧均匀。

06展示框配置

每个分区对应 展示框/ 下的一个子文件夹，里面固定放两份文件：配置与内容。

展示框 / 索引.js

window.RAW_FRAME_INDEX = {
  frames: [
    {
      dir: "展示框/AA-FR-HM-“首页”",
      config: "AA-CF-HM-“首页配置”.js"
    },
    { dir: "展示框/AB-FR-WR-“文章”", config: "AB-CF-WR-“文章配置”.js" }
    // …
  ]
};

配置文件

RawaeaFrame.define({
  code: "AA-FR-HM",            // 必须与轮盘第一段一致
  name: "首页",
  english: "HOME",
  eyebrow: "WELCOME · 序章",   // 展示框顶部眉标
  note: "受引力约束的一小块安静", // 展示框底部注记
  content: ["AA-CN-HM-“首页内容”.js"]  // 内容文件，可多个
});

内容文件

内容文件通过 RawaeaFrame.content(编号, 数据) 注册。最短的写法只需要一段 html：

RawaeaFrame.content("AA-FR-HM", {
  html: `
    <div class="home">
      <p class="overline">A QUIET CORNER IN THE COSMOS</p>
      <h1 class="display-title">在引力之外，<br><em>收藏一束光。</em></h1>
      <p class="lead">你好，我是 RaWaEa。</p>
    </div>
  `
});
提示：内容文件是普通的 JS 文件，反引号（` `）包住的就是 HTML。请在中文引号 “ ” 里写字，不要在里面再使用反引号，以免提前结束字符串。

新增一个分区的完整步骤

  1. 复制 轮盘/AE-WL-CT-“联系”.js，改名为 轮盘/AF-WL-XX-“新名字”.js，把 code 改成 AF-WL-XX，改好 name / english / icon / accent。
  2. 在 轮盘/索引.js 的 files 末尾追加这个新路径。
  3. 复制整个 展示框/AE-FR-CT-“联系”/ 为 展示框/AF-FR-XX-“新名字”/，两份文件同步改名并把编号换成 AF。
  4. 在 展示框/索引.js 的 frames 里追加 { dir, config }。
  5. 刷新页面，第六个分区就会出现在轮盘上。

07内容写法

展示框里的 HTML 片段完全自由，但推荐沿用现有的类名，这样能直接继承青蓝样式。

常用类名

类名用途
.overline冰蓝小眉标，例：SELECTED NOTES
.display-title首页大标题，<em> 部分为冰蓝斜体
.lead正文导语
.section-heading分区标题 + 右侧说明
.post-list / .post-row文章列表
.project-grid / .project-card项目卡片
.masonry / .masonry-item光影瀑布流图片墙
.contact-layout / .contact-card联系方式

让元素可交互

在任意元素上加这三个属性，就会自动接上交互：

属性效果
data-goto="1"跳到第 2 个分区（编号从 0 开始）
data-post="0"打开文章数组中第 1 篇的阅读层
data-copy="hello@rawaea.me"点击复制文本并提示

文章：数组 + 占位符

「文章」分区的配置里多一个 posts 数组，列表会自动生成。模板中写 {{POSTS}} 的位置会被替换成文章行。

RawaeaFrame.content("AB-FR-WR", {
  posts: [
    {
      date: "2026.10.28",
      tags: "设计 / 思考",
      reading: "6 min",
      title: "在黑洞边缘，练习安静",
      body: `<p>正文段落……</p>
             <blockquote>引用一句……</blockquote>`
    }
  ],
  html: `
    <div class="writing">
      <header class="section-heading">…</header>
      <div class="post-list">{{POSTS}}</div>
    </div>
  `
});
注意：{{POSTS}} 只出现一次即可；文章正文里可以随意使用 <p>、<blockquote>、<strong>，阅读层会自动套用排版。

光影：瀑布流图片

「光影」的内容文件里放一个 gallery 数组，模板中的 {{GALLERY}} 会展开成瀑布流。每个条目需要 src，可选的 title / place 显示在图片底部，credit 会写进悬停提示；图片高度按原始比例自动计算，桌面三列、手机两列。

RawaeaFrame.content("AD-FR-GL", {
  gallery: [
    {
      src: "assets/photos/hangzhou.jpg",
      title: "西湖的午后",
      place: "浙江 · 杭州",
      credit: "Yinweichen / Wikimedia · CC BY-SA 4.0"
    }
  ],
  html: `
    <div class="gallery">
      <div class="masonry">{{GALLERY}}</div>
    </div>
  `
});

换成自己的照片

把照片放进 assets/photos/，用 1600px 宽左右最合适；然后把 src 指过去即可。也可以直接替换同名的 12 张图，版式不用改。

授权：现有 12 张照片来自 Wikimedia Commons（CC BY-SA / CC BY / CC0），作者与协议见「背景影像」章节。换成自己的照片时，记得同步更新 credit 与手册里的清单。

08背景影像

整站背景是三张 NASA / JPL-Caltech 黑洞影像，每次打开随机挑一张；停留时每 70 秒自动换一张，切换分区时也会再抽一张。换图用 1.6 秒交叉淡入，右下角同步显示出处。

影像池

文件画面来源
assets/blackholes/01-tidal.jpg黑洞撕裂恒星（3482×1959）NASA/JPL-Caltech · PIA20027 · 公有领域
assets/blackholes/02-echo.jpg吸积盘与尘埃环（3840×2160）NASA/JPL-Caltech · PIA23866 · 公有领域
assets/splash-blackhole.jpg黑洞与喷流（5120×2880，兼作开屏）NASA/JPL-Caltech · PIA22085 · 公有领域

想固定看某一张，在地址后加 ?bh=1、?bh=2 或 ?bh=3（顺序同上表）；不加则随机。新增影像：把 jpg 放进 assets/blackholes/，再在 app.js 顶部的 BLACKHOLES 数组里加一条 { src, credit } 即可。

背景亮度集中在 styles.css 的 .cosmos-photo：filter: blur(1.4px) brightness(0.9) saturate(1.03)；暗角在 .cosmos-veil。想更亮就把 brightness 往上调，同时把暗角的 alpha 压低；想更清晰就把 blur(1.4px) 改小或删掉。

为什么轻微虚化：黑洞原图对比度很高，直接铺满会压住文字。1.4px 的模糊既保留了星云与吸积盘的质感，又让玻璃面板上的字更清楚。

玻璃：一直半透明

轮盘与展示框使用固定不透明度（展示框 34%、轮盘 30%），不再随天气、分区或悬停改变透明度；只保留 24px 的磨砂模糊、极细的描边与顶部高光。相关样式在 .frame-glass、.wheel-glass、.display-frame 三处。

10常见问题

背景是哪张黑洞照片？

背景在三张 NASA/JPL-Caltech 黑洞影像之间随机轮换：PIA20027（黑洞撕裂恒星）、PIA23866（吸积盘与尘埃环）、PIA22085（黑洞与喷流，也是开屏图）。每次打开随机一张，停留时每 70 秒换一张，切换分区也会换。右下角会标注当前影像的编号。

为什么背景是虚的？

黑洞原图对比度很高，直接铺满会压住文字，所以加了 1.4px 的轻微模糊与一层暗角。想要更锐利，把 .cosmos-photo 的 blur(1.4px) 改小或删掉即可。

光影里的照片能换吗？

能。12 张照片都在 assets/photos/，替换同名文件即可；也可以在 AD-CN-GL-“光影内容”.js 的 gallery 数组里增删条目。每张图的作者与授权见「背景影像」章节的表格。

为什么左边的轮盘只露出一半？

这是本版的版式设计：轮盘整体左移，像嵌在屏幕边缘的罗盘。露出的右半圈正好朝向展示框，当前选中的分区永远停在 3 点钟方向。被裁掉的标签仍然可用：点下方的上下箭头、按 ← / →，或在轮盘上滚动即可切换。手机端会自动恢复为完整轮盘。

开屏页能去掉吗？

可以。临时跳过用 index.html?enter；想永久去掉，把 index.html 里的 <section class="splash">…</section> 整段删除即可，进入状态会自动生效。

图片加载失败会怎样？

失败的图片会保留一个占位框（半透明 + 最小高度），不会让瀑布流塌掉。检查路径大小写与实际文件名即可。

打开后一片漆黑，或出现 SIGNAL LOST

说明浏览器没有读到配置。请确认 index.html、app.js、轮盘/、展示框/ 在同一层文件夹里，并且 轮盘/索引.js 存在。如果移动过整个文件夹，路径保持不变即可。

改了文字，页面没有变化

浏览器缓存了旧的 JS 文件。按 Ctrl + F5 强制刷新；若仍不生效，检查是否改错了分区（编号是否对应），以及 content 里列出的文件名与实际文件名是否完全一致（包含 “ ”）。

展示框显示 “NO SIGNAL · 这一站还没有收到内容”

轮盘有这一项，但展示框没找到对应子文件夹。检查三处：展示框/索引.js 是否登记；配置里的 code 第一段是否与轮盘一致；内容文件是否写进了 content 列表。

轮盘顺序乱了 / 少了某一项

轮盘按第一段编号排序（AA→AB→AC…）。如果新文件没有出现在 轮盘/索引.js 的 files 里，它就不会被加载。

内容太长，把展示框撑开了

不会撑开：展示框内部固定高度、内部滚动。如果希望一屏读完，请精简卡片数量或调小字号；如果希望阅读更从容，可以在内容最外层套 <div class="writing"> 之类的大段落。

可以去掉某个分区吗

可以。删除 轮盘/索引.js 中对应的那一行即可（文件与展示框文件夹可保留作备份）。剩余分区会自动重新均分盘面。若要恢复，把路径加回去即可。

中文引号打不出来怎么办

文件名里的 “ ” 是标记的一部分，建议直接从现有文件复制。Windows 文件名不允许半角双引号 "，所以请勿替换成半角。

想换成自己的域名 / 部署

把整个文件夹上传到任意静态托管即可，不需要后端。托管平台对中文文件名支持良好，但为了稳妥，建议保持 UTF-8 编码上传。

11维护建议

  • 先备份再动手：改配置前复制一份 轮盘/ 与 展示框/，出问题能立刻还原。
  • 一次只加一个分区：加完立刻刷新验证，比一次性改五处更容易定位问题。
  • 编号就是秩序：不要为了好看随意改第一段字母，它决定了轮盘顺序和展示框的匹配。
  • 标签可以随意写：“ ” 里的文字只影响阅读体验，不影响程序。
  • 配色克制：强调色保持一两个色相，背景保持一张图，冰蓝留给框架与重点。
一句话记住这套结构：轮盘决定「去哪」，展示框决定「看到什么」，编号决定「谁对谁」。改内容只改展示框，改顺序只改轮盘索引。
